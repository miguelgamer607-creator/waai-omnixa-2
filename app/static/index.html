Al conectar un proveedor remoto, la conversación reciente que necesite el modelo se transmite al servidor del proveedor. Nunca pongas claves API en el navegador ni en el repositorio.

El modelo se configura con variables de entorno en el servidor. Sin esa configuración, Waai usa reglas básicas. Una API compatible con OpenAI no implica que el modelo sea de OpenAI.

Guía de configuración de modelo e iniciativa

Acceso privado

En modo desarrollo no hace falta token. En producción, pega el token configurado en el servidor. Se guarda solamente en el almacenamiento local de este navegador.

Instalación

Puedes instalar la aplicación desde el menú del navegador si este ofrece la opción. Una mascota dentro de Waai no es todavía una ventana de superposición sobre otras aplicaciones de Android; eso necesita una versión nativa.
